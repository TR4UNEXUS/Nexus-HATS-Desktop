# Nexus HATS Desktop for macOS

This folder is part of the combined Windows/Mac source tree. Keep the parent
`shared` folder alongside it. Read [the root README](../README.md) for build,
protection and update instructions. Run the root GitHub Actions workflow to build
and verify the universal DMG on Apple Silicon and Intel Macs.

This adaptation includes the original project's macOS 2.3.1 card-detection fix.
